# 🎨 WhatsApp Sticker Converter

Convert sticker packs from [stickers.wiki](https://stickers.wiki)
to WhatsApp-compatible sticker packs.

## Features
- 🔗 Scrape sticker langsung dari link stickers.wiki
- 📁 Upload manual file (.webp / .png / .jpg)
- ✂️ Auto-split per 30 stiker (batas WhatsApp)
- 📦 Download sebagai ZIP siap import
- 🎯 Auto-resize ke 512x512 WebP

## Deploy ke Streamlit Cloud

1. Fork repo ini
2. Buka [share.streamlit.io](https://share.streamlit.io)
3. Klik "New app" → pilih repo ini
4. Set main file: `app.py`
5. Klik Deploy!

## Cara Pakai
1. Paste link dari stickers.wiki atau upload gambar
2. Klik "Konversi Sekarang"
3. Download file ZIP
4. Import ke WhatsApp via Sticker Maker app
